# VHM: Versatile and Honest Vision Language Model for Remote Sensing Image Analysis

## Problem
RS VLMs were trained only on factual questions about objects that exist in the image, so they happily answer nonsense, for example giving the colour of an object that is not there. Their captions also covered only a few prominent objects, limiting what the model learns about the whole scene.

## Approach
VHM follows the LLaVA recipe (Sec 3.1): CLIP-Large at 336 px, Vicuna-v1.5 7B, with tokens from ViT layers 8, 16 and 24 concatenated and passed through a compression layer and projector. Training (Sec 3.2) starts from LLaVA weights: pretraining all components on VersaD for one epoch on 16 A100-80G GPUs, then supervised fine-tuning (vision encoder frozen) on VersaD-Instruct, VariousRS-Instruct and the honesty set HnstD on 8 A100s. HnstD pairs factual questions with deceptive ones (about non-existent objects chosen by random, popular or adversarial sampling, or about colour in panchromatic images) so the model learns to say the premise is false (Appendix C.1).

## Data and benchmarks
- VersaD: about 1.4M images from Million-AID, CrowdAI, fMoW, CVUSA, CVACT and LoveDA (0.08 to 153 m per pixel; Table 1) with multi-sentence captions generated by Gemini-Vision. A manual check of 315 captions (2,002 sentences) found 73% fully accurate, 10% fully inaccurate, 17% partly accurate sentences, which the authors summarise as 82.3% accuracy (Sec 2.1, Appendix B.2).
- HnstD: over 45k manually checked QA pairs from DOTA-v2 and FAIR1M across presence (yes/no), colour (open-ended), absolute position and relative position (five-way single choice); test sets of 100 to 400 questions per task (Table 2).
- Evaluation: scene classification (5 datasets), RSVQA-LR and HR, DIOR-RSVG grounding, plus new tasks (counting, image modality, resolution estimation, geometric measurement, building vectorizing, multi-label classification, honest QA; Table 13).

## Key results
- Honest QA (Table 11): presence 85.06; colour 81.50 factual, 93.33 (absent object) and 93.00 (panchromatic); absolute position 76.79 factual, 90.67 deceptive; relative position 47.52 factual, 87.67 deceptive. Qwen-VL-Chat scores 8.33 on deceptive colour questions about absent objects; CogVLM reaches 100 on panchromatic deception but only 31.25 on factual colour.
- New tasks (Table 5): image modality 95% accuracy (test set of only 20 images), resolution MAE 0.24, counting MAE 6.75, geometric measurement MAE 12.82, building vectorizing C-IoU 71.25%, multi-label F1 51.87%.
- Common tasks: scene classification average 85.13 vs 80.17 for LHRS-Bot (Table 6); RSVQA-LR 89.33 vs 89.19 (Table 7); RSVQA-HR zero-shot 73.75 (Table 8); DIOR-RSVG 56.17 at 336 px (Table 9).
- Pretraining on VersaD beat SkyScript pretraining on grounding (59.52 vs 16.01, Table 10) despite SkyScript's higher caption accuracy (96.1%), suggesting richer captions matter more than perfect ones.

## Limitations
The authors state VHM cannot do pixel-wise perception, so no segmentation or change detection (Sec 5). Optical imagery only in training and evaluation (SAR appears only as a class in the modality-recognition task), single date, 7B on GPU. Honesty covers four question templates; relative position factual accuracy (47.52) is much lower than its deceptive accuracy (87.67), which suggests some answers become refusals at the cost of correct factual answers (our reading, not the authors' claim). Honesty is a binary learned behaviour, not a calibrated probability. Captions are themselves model generated (about 18% inaccurate by their own check); colour labels also come from Gemini-Vision.

## What it means for EvidEO
- This is the nearest RS prior art for "the assistant says no when the premise is wrong". Cite it honestly rather than claiming no RS assistant refuses.
- The difference to stress: VHM refuses based on what the language model believes it sees; EvidEO abstains based on instrument quality signals (cloud fraction, SAR noise floor, mask size, temporal gap) with a calibrated threshold. VHM gives no confidence score, no scene IDs, dates or masks.
- Adopt the HnstD idea for EvidEO's parser tests: include deceptive questions ("how much rice is flooded in a district with no rice", "NDVI on a date with no Sentinel-2 pass") built with random, popular and adversarial distractors, and require the system to correct the premise.
- Watch the factual-versus-deceptive gap: measure both refusal correctness and false refusals so EvidEO's abstention does not become over-cautious.

## Full-text check (2026-10-14)
Ingredients (paper's own system as built and evaluated):
- C1 Calibrated per-answer confidence: No. No confidence output or calibration measure anywhere (Sec 4, Tables 5 to 12).
- C2 Threshold abstention with a next step: part. Learned premise rejection on deceptive questions (Sec 2.2, Table 11), which states why (the object is absent or the image is panchromatic) but uses no confidence threshold and suggests no fix.
- C3 Scene receipts that reproduce: No. Single uploaded image, no scene IDs or re-run checks.
- C4 SAR chosen automatically under cloud: No. Optical RGB inputs; SAR (MSAR) only appears as a class to recognise in the modality task (Table 3, Table 13).
- C5 CPU or offline deployment: No. 7B model trained on A100s; no CPU inference reported.
- C6 Plain-language questions for non-experts: part. Free-form chat (Fig 5), but evaluation uses templated questions with task identifiers; no non-expert study.

What the abstract-level entry got wrong or left unconfirmed:
- Author list was missing Litong Feng.
- The 95% image-modality accuracy rests on a 20-image test set (Table 3), so it is weak evidence.
- HnstD test sets are small (242 presence, 600 colour, 400 per position task), worth noting when citing the honesty numbers.

Novelty implications: two parts (C2, C6), no full Yes. Does not threaten the "no more than two" claim.
